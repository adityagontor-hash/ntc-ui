# NTC FIK UI — Redesign Konsep Website

Kumpulan hasil redesign konsep website Nursing Training Center FIK UI, dibuat bersama Claude.

## Isi repo
- `index.html` — versi terbaru (sama dengan ntcui-beranda-v3.html), langsung terbuka via GitHub Pages
- `ntcui-beranda-v3.html` — **versi terbaik**: desain custom (bento grid, motif EKG, tipografi Bricolage Grotesque + IBM Plex Sans), pakai foto & data asli dari Company Profile PDF, logo HD sudah tersemat
- `ntcui-redesign.html` — redesign awal: perbaikan responsivitas, kontras, navigasi, SEO, search & filter pelatihan
- `ntcui-redesign-pro.html` — versi bergaya marketplace pelatihan (hero carousel, kartu pelatihan, testimoni)
- `template-penempatan-ntcui.html` — blueprint penempatan konten & gambar per halaman dari Company Profile PDF
- `logo-ntc-HD.png` — logo NTC hasil upscale AI super-resolution (4x, dari 114x46 ke 456x184)

## Catatan
File `*.html` bersifat statis (self-contained) — bisa langsung dibuka di browser, atau di-deploy ke GitHub Pages.
